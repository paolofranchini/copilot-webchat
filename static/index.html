🤖 Copilot CLI Webchat @ raspberrypi

Impostazioni

Sessioni

La sidebar mostra le sessioni native Copilot. Eliminarne una rimuove definitivamente cronologia e file.

Notifiche risposte

Ricevi una notifica quando una risposta arriva mentre la webchat è in background o stai leggendo un'altra chat. Non invia il testo della conversazione. La pagina deve restare aperta; non funziona con la PWA completamente chiusa.

Riavvio servizio

Applica gli aggiornamenti del backend. Richiede systemd e nessuna sessione Copilot in esecuzione.

Server MCP disponibili

Gestisci i server MCP configurati nella webchat.

Supporta stdio locale (`command`, `args`, `env`) e HTTP Streamable (`type: "http"`, `url`, `headers`, `tools`). I server abilitati vengono usati nelle chat con permessi MCP.

Skill e plugin disponibili

Le selezioni valgono per le sessioni future di Copilot, anche fuori dalla webchat.

HTTPS e installazione

Scarica la CA per fidarti del certificato HTTPS su questo dispositivo.

Scarica certificato CA HTTPS: porta 7891 · HTTP: porta 7890 · Non disponibile offline.

Secret Direct Line

Inserisci un secret Direct Line rigenerato. Viene cifrato sul server e non viene mai mostrato di nuovo. La chiave di cifratura è conservata separatamente con permessi privati.
